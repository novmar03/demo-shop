# Демо-магазин CloudPayments

Сайт: https://novmar03.github.io/demo-shop/

Восемь товаров, отдельная страница корзины, изменение количества, удаление, автоматический расчёт суммы и сохранение корзины в localStorage. На карточке после добавления отображаются количество и кнопки «−» / «+». Интерфейс, уведомления, подписи доступности и заголовки страниц — на русском.

## Запуск

Нужен Node.js 20 или новее. Установка зависимостей не требуется.

```sh
npm start
npm test
```

Локальный адрес: http://localhost:3000.

## Структура

- `src/products.js` — товары, русские описания, демонстрационные цены в рублях и фотографии.
- `src/cart.js` — операции с корзиной, проверка сохранённых данных и структурированный `orderSnapshot(cart, orderId)`.
- `src/ui.js` — форматирование, карточки, изображения и счётчики.
- `src/app.js` — каталог, корзина, навигация и запуск оплаты.
- `src/styles.css` — фирменные цвета, типографика, кнопки и адаптивная сетка.

Снимок заказа содержит `orderId` (пока null), валюту, товары, количества, суммы строк, общее количество и итоговую сумму. Кнопка «Оплатить» отправляет событие `demo-store:checkout` со снимком и открывает официальный виджет CloudPayments. `src/payment.js` загружает SDK непосредственно с https://widget.cloudpayments.ru/bundles/cloudpayments.js и вызывает `start`: Public ID передаётся в `publicTerminalId`, сумма — из текущего снимка, описание — «Покупка в демо-магазине», валюта — RUB, схема — Single. Передаются товары и количества; будущий `orderId` передаётся как `externalId`. Повторные клики блокируются до закрытия, ошибки позволяют повторить попытку. Результат доступен в событии `demo-store:payment-result`. Корзина не очищается по клиентскому результату.

Документация: https://developers.cloudpayments.ru/#ustanovka-vidzheta. Режим терминала определяется настройками CloudPayments. Для подтверждения заказов в промышленной эксплуатации сервер должен проверять цены, создавать идентификатор заказа и обрабатывать уведомления Check/Pay; GitHub Pages не выполняет эту серверную часть.

Максимум — 999 единиц одного товара. В корзине минимум — одна единица; полное удаление доступно отдельно. На карточке «−» при одной единице убирает товар. При блокировке localStorage используется память страницы. При изменении каталога неизвестные идентификаторы удаляются из восстановленной корзины; существующие товары сохраняются.

## Публикация

GitHub Pages публикует ветку `main`. Корзина имеет статический вход `cart/index.html` и доступна по `/demo-shop/cart/`, включая прямое открытие и обновление. Пути учитывают каталог установки. Файл `.nojekyll` отключает обработку Jekyll.

Сетка: четыре колонки на компьютере, две на планшете и одна на телефоне. На узком экране блок заказа перемещается под товары.

## Платежные сценарии

Панель внизу каталога и корзины переключает «Виджет» (`cart/`) и «Платежные блоки» (`payment-blocks/`). Check-out показывает только уведомление о будущей доступности. Корзина в шапке всегда ведёт к виджету.

`src/blocks.js` загружает официальный `paymentblocks.js` и монтирует `cp.PaymentBlocks` под суммой заказа. При изменении корзины предыдущий экземпляр демонтируется, новый получает актуальный снимок заказа. При навигации или пустой корзине конструктор демонтируется; незавершённая загрузка не создаёт форму на покинутой странице. Используются тот же Public ID и описание, что у виджета.

## Checkout

`checkout/` содержит собственную форму под итоговой суммой. `src/checkout.js` загружает https://checkout.cloudpayments.ru/checkout.js, инициализирует `cp.Checkout` с Public ID и контейнером формы и вызывает `createPaymentCryptogram()`. Поля используют `data-cp`, без атрибутов `name`. Карточные данные и криптограмма не сохраняются и не логируются; после успешного создания форма очищается. Корзина и сумма общие для всех сценариев.

На GitHub Pages доступна только демонстрация формирования криптограммы. Завершение платежа НЕ реализовано: требуется отдельно развёрнутый сервер, проверяющий каталог и сумму, использующий API Secret из защищённого хранилища и вызывающий API оплаты по криптограмме, включая обработку 3-D Secure. Нельзя добавлять API Secret в этот репозиторий. Кнопка честно обозначена «Проверить Checkout», результат не выдаётся за оплату.
