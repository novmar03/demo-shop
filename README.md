# Демо-магазин CloudPayments

Сайт: https://novmar03.github.io/demo-shop/

Демонстрация трёх сценариев: Виджет (`cart/`), Платёжные блоки
(`payment-blocks/`) и Checkout (`checkout/`). Общие каталог и корзина.

## Начать проверку

Основной документ для аналитика: [карта кода, контракт API, правила и матрица
приёмки](docs/VALIDATION.md). В нём же перечислены результаты ревью и открытые риски.

```sh
npm start
npm test
```

Node.js 20+. Приложение не требует установки зависимостей.
Локальный адрес: http://localhost:3000. server.js не проводит платежи.

## Настройки и публикация

Публичные настройки находятся в `src/config.js`. API Secret хранится только
в Yandex Lockbox, не в браузере или репозитории. Checkout обращается к API Gateway;
исходник облачного обработчика в репозиторий не включён.

GitHub Pages публикует `main`. Изменения frontend не обновляют Cloud Function.
Публичный справочник серверных цен — `backend/catalog.cjs`, инструкция —
`backend/README.md`. Для изменения каталога проверять обе стороны.

Виджет и блоки используют SDK CloudPayments; Checkout создаёт криптограмму
и передаёт ID/количества backend. Успех очищает демо-корзину, отказ сохраняет.
Клиентский результат не является серверным подтверждением заказа.

## Оформление

Шрифты Stolzl Book/Regular/Medium и палитра общие с лендингом.
История и размеры дизайна: `LANDING.md`. Статические изображения — в `public/`.
CSS читается в порядке подключения: styles, footer, landing, study.
Последующие правила и media queries могут переопределять предыдущие.

Для единообразного форматирования исходников использован Prettier 3.6.2.

Сопоставление названий с официальной документацией: [CloudPayments](docs/CLOUDPAYMENTS.md).
