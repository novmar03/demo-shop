# Синхронизация каталога Checkout

Главная, корзина, Виджет и Платёжные блоки используют новые товары из
`src/products.js`. Для Checkout цены рассчитывает отдельная функция Yandex Cloud.
Её исходного кода и доступа к развёртыванию в этом репозитории нет.

Перед приёмом новых товаров добавьте `catalog.cjs` в файлы действующей функции
и замените её прежний справочник на этот каталог. Например, в CommonJS:

```js
const PRODUCTS = require('./catalog.cjs');
// В существующей проверке items:
const product = PRODUCTS[item.id];
// Неизвестные ID отклонять. Проверять, что quantity — целое от 1 до 999.
// Сумму рассчитывать исключительно как product.price * item.quantity.
```

Название переменной и место подключения нужно согласовать с текущим обработчиком.
`catalog.cjs` содержит только публичные названия и цены в рублях, не секреты.
Параметры Lockbox, Public ID, API Secret, маршруты и обработку 3-D Secure менять
из-за каталога не требуется.

Новые ID взяты из оригинального магазина. Они не совпадают с прежними ID 1–10:
так старый обработчик должен отклонить неизвестные товары, а не списать прежние
цены за новые позиции. Не добавляйте подмену новых ID на старые и не принимайте
итоговую сумму с клиента без серверной проверки.

Контрольные суммы: кепка — 2100 ₽; две кепки и носки — 4690 ₽;
по одной штуке всех восьми товаров — 12890 ₽.

После изменения справочника сохраните новую версию функции и проверьте тестовую
оплату, отказ и 3-D Secure. До этого публикация GitHub Pages сама по себе
не обновляет каталог облачной функции, и Checkout может отклонять новые ID.
